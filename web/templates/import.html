Import

CSV import - monthly update

The spreadsheet dump format: <id>,<name>,<deposit>,<current value>. Only the id, deposit and value columns are read - the name and any extra columns are discarded. Each applied row writes a snapshot for that asset in the month of the snapshot date (replacing it if one already exists); income goes on the ledger instead.

CSV format guide
ColumnUsedNotes
idyesThe asset id (Manage page / /asset/<id>). Rows without an id are skipped, so header rows and blank spreadsheet padding need no cleanup - their name column still shows in the preview. An id that matches no asset is warned about and skipped.
namenoWhatever the spreadsheet calls it - ignored, shown in the preview for orientation only.
deposityesCumulative total deposited into the asset so far. Tolerates £2,500.00-style noise.
valueyesThe asset's current value.
anything elsenoDiscarded.

Preview first: every row is validated against the database before anything is written. Rows targeting closed assets are warned about and not applied, and the commit warns you when it ended up updating nothing for the chosen month. Validation errors (bad amounts) block the commit.
